# Quantum Tomography
Repositório destinado ao desenvolvimento de um projeto de tomografia quântica na matéria de aspectos matemáticos e computacionais da mecânica quântica. O principal objetivo do projeto é fazer uma breve discussão sobre a tomografia quântica para um problema específico (a princípio o problema de 2-qubits), e a partir disso, desenvolver códigos que resolvam o problema, tentando elaborar um que resolva na força bruta, e explorar diferentes algoritmos para o problema e compará-los.

## Estruturação do código
Elaborar computacionalmente uma máquina que gere os estados aleatórios (talvez simular algum experimento real). Construir uma função que realiza as medidas necessárias para caracterizar o estado (ver se é possível simular uma situação real (não exata)). Resolver a tomografia na força bruta. Resolver a tomografia usando algum algoritmo. Comparar características entre os dois algoritmos.
